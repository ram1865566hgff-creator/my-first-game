# Слайд вперед — современный интерфейс Windows

Современная Windows-программа с новым синим значком презентации и микрофона.

**Разработчик: Рамазанов Роман Валерьевич**

## Голосовые команды

- **«Дальше»** — следующий шаг анимации *на текущем слайде*; если шагов больше нет, остаёмся на слайде.
- **«Назад»** — предыдущий шаг анимации без смены слайда.
- **«Следующий слайд»** — следующий слайд, пропуская все оставшиеся анимации.
- **«Предыдущий слайд»** — предыдущий слайд.

Для анимаций требуется настольный Microsoft PowerPoint (режим показа слайдов): используется безопасный вызов GotoClick, предотвращающий случайное перелистывание. Для слайдов используется GotoSlide. Если показ PowerPoint не доступен, «Дальше» и «Назад» ничего не переключают. В других программах гарантированы только попытки перехода между слайдами через PageUp/PageDown.

## Установка

1. Перейдите в [GitHub Actions](https://github.com/ram1865566hgff-creator/my-first-game/actions?query=branch%3Aslidevoice-windows).
2. Выберите последнюю успешную сборку **Build Слайд вперед Windows EXE**.
3. В разделе Artifacts скачайте **Slaid-Vpered-Windows-exe**.
4. Распакуйте архив и запустите **Слайд вперед.exe** на Windows 10/11 64-bit.
5. Разрешите доступ к микрофону, в программе нажмите «НАЧАТЬ СЛУШАТЬ», откройте презентацию на весь экран.

Офлайн распознавание русского языка Vosk включено в EXE. Для первого запуска скачивать модель отдельно не нужно. Для запуска кода в Windows требуется Python 3.11 и пакетный файл УСТАНОВИТЬ_И_ЗАПУСТИТЬ.bat.

Отдельный ICO создаётся в assets/slide-vpered.ico из assets/slide-vpered-art.jpg. EXE подписанным сертификатом не является, Windows может показать SmartScreen.

Автоматические тесты проверяют логику команд. Работу микрофона и PowerPoint проверьте на вашем компьютере.


### Обновлённый интерфейс
Светлое окно в стиле макета: подпись разработчика по центру над названием, большой логотип, статус и кнопка запуска, выбор микрофона, настройки, четыре горизонтальные команды и информационная панель. Доступна прокрутка на небольших экранах.


### Компактное окно
По умолчанию окно открывается размером **800 × 690 пикселей** вместо 1020 × 930. Логотип, текст и отступы пропорционально уменьшены; вертикальная прокрутка сохраняет доступность всех элементов. Минимальный размер — 660 × 520 пикселей.


## Исправление двойного перехода

Команды «Следующий слайд» и «Предыдущий слайд» теперь защищены от дублирующихся результатов распознавания: почти одновременное двойное распознавание в течение 0,45 секунды выполняется только один раз. Каждая следующая отдельно произнесённая команда выполняется без ожидания 2,7 секунды. При смене направления команда выполняется сразу. Команды анимации «Дальше» и «Назад» не ограничиваются этим интервалом. При каждом новом запуске прослушивания защита сбрасывается.

В PowerPoint используется прямой переход GotoSlide; количество автоматически проигрываемых слайдов зависит также от настроек переходов самой презентации. Если и с новой версией слайды автоматически пролетают, проверьте параметр «После ... секунд» на вкладке «Переходы».
