# SlideVoice v2 — голосовые анимации и слайды для Windows

Управление **четырьмя командами** в настольном Microsoft PowerPoint во время показа:

- **Дальше** — показать очередную анимацию/строку на текущем слайде.
- **Назад** — отменить предыдущий шаг анимации на текущем слайде.
- **Следующий слайд** — непосредственно перейти на следующий слайд, минуя оставшиеся анимации.
- **Предыдущий слайд** — непосредственно перейти на предыдущий слайд, минуя анимации.

Для PowerPoint команда «Дальше» не перелистывает слайд, когда анимации закончились; «Назад» не возвращает на предыдущий слайд. Прямые переходы между слайдами используют Microsoft PowerPoint COM.

При работе в PDF, браузере, LibreOffice и других программах действуют общие сочетания клавиш: «Дальше» / «Назад» = стрелки вправо/влево, «Следующий слайд» / «Предыдущий слайд» = Page Down / Page Up. В таких программах точное разделение анимации и слайдов **не гарантируется**.

## Скачать EXE (Windows 10/11 x64)

Откройте https://github.com/ram1865566hgff-creator/my-first-game/actions?query=branch%3Aslidevoice-windows, выберите успешную сборку в ветке slidevoice-windows и скачайте артефакт SlideVoice-Windows-exe. Извлеките SlideVoice.exe.

Запустите EXE, выберите микрофон, нажмите «НАЧАТЬ СЛУШАТЬ» и затем откройте PowerPoint в полноэкранном режиме показа. Для каждой команды делайте небольшую паузу. Вся обработка голоса локальная; после сборки интернет не нужен.

## Исходный код

Для Windows с Python 3.11 запустите УСТАНОВИТЬ_И_ЗАПУСТИТЬ.bat, которая установит зависимости и скачает русскую Vosk-модель.

Тесты: python -m unittest discover -s tests -v.

EXE собирается GitHub Actions через PyInstaller и не подписан сертификатом. Поведение COM проверяется на реальном PowerPoint пользователем; автоматические тесты проверяют принятие и маршрутизацию команд.
