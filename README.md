# SlideVoice 2.1 — защищённое управление анимациями и слайдами

Исправлена ошибка версии 2.0: команда «Дальше» больше не листает презентацию, если анимаций нет или они закончились.

| Команда | Действие в настольном Microsoft PowerPoint |
| --- | --- |
| **«Дальше»** | Следующая анимация *на этом же слайде*. Если её нет, не происходит ничего |
| **«Назад»** | Предыдущий шаг анимации *на этом же слайде*. На первом шаге слайд не меняется |
| **«Следующий слайд»** | Перейти к следующему слайду, пропуская анимации |
| **«Предыдущий слайд»** | Перейти к предыдущему слайду, пропуская анимации |

Теперь для шагов анимации используется **SlideShowView.GotoClick** (PowerPoint COM), а не стрелки клавиатуры. Поэтому анимационная команда не может вызвать переход на соседний слайд. Команда слайдов использует **GotoSlide**.

**Важно:** точные шаги анимации доступны только в **настольном PowerPoint на Windows** (режим показа слайдов). Если показ PowerPoint не найден, «Дальше» и «Назад» ничего не переключают и программа объясняет причину в строке последней команды. Для PDF, WPS, LibreOffice и браузерных презентаций остаются только голосовые команды переключения *слайдов* — Page Down / Page Up; анимации в них не контролируются, поскольку нельзя гарантировать, что стрелка не перелистнёт слайд.

PowerPoint сообщает лишь число *по щелчку* запусков анимации. Эффекты «После предыдущего» и «С предыдущим» могут срабатывать автоматически, отдельно голосом они не перелистываются.

## Запуск

1. Скачать ZIP со сборкой: https://github.com/ram1865566hgff-creator/my-first-game/actions?query=branch%3Aslidevoice-windows
2. Извлечь SlideVoice.exe, запустить на Windows 10/11 (64-bit).
3. Выбрать микрофон, нажать «НАЧАТЬ СЛУШАТЬ», переключиться в полноэкранный показ PowerPoint.
4. Произносить «Дальше», «Назад», «Следующий слайд», «Предыдущий слайд».

Без интернета после установки. Требуется рабочий микрофон, настольный PowerPoint для анимаций. EXE не подписан цифровой подписью.
