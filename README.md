# SHADOW STRIKE — Neon Warfare

Original offline action platformer inspired by 2D run-and-gun classics (not affiliated with Contra or Konami).

Three missions: jungle, neon city, reactor; touch controls; bosses, parallax, explosions, powerups.

To build an APK, run the GitHub Action or run `gradle assembleDebug` with Android SDK 35 installed. APK artifact named ShadowStrike.apk.

Game preview: open `app/src/main/assets/index.html` in a browser in landscape.

Controls: touch directions / Jump / Fire / Grenade / Dash. Desktop: WASD/Arrows, J shoot, K jump, L grenade, Shift dash, P pause.

No internet, trackers, or runtime external dependencies are required. Android 6+.
