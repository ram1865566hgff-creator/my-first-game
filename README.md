# SlideVoice — голосовое переключение слайдов для Windows

**«Дальше»** — следующий слайд. **«Назад»** — предыдущий слайд.
Слово-обращение не нужно. Программа работает локально и без интернета после установки речевой модели.

## Скачать готовую Windows-программу

1. Откройте GitHub → Actions → Build SlideVoice Windows EXE.
2. Найдите успешный запуск сборки для ветки slidevoice-windows.
3. Скачайте артефакт SlideVoice-Windows-exe и извлеките SlideVoice.exe.

Прямая страница ветки: https://github.com/ram1865566hgff-creator/my-first-game/tree/slidevoice-windows
Сборки: https://github.com/ram1865566hgff-creator/my-first-game/actions?query=branch%3Aslidevoice-windows

Windows 10/11, 64-бит. Программа отправляет стрелки в активное окно, поэтому откройте показ слайдов на весь экран. Поддерживаются PowerPoint, LibreOffice Impress, PDF и браузерные презентации, переключаемые стрелками.

## Пользование

Выберите микрофон → «Начать слушать» → откройте презентацию → скажите «Дальше» или «Назад». Вернитесь в SlideVoice и нажмите «Остановить» после завершения показа.

## Работа из исходников

Установите Python 3.11 для Windows и откройте УСТАНОВИТЬ_И_ЗАПУСТИТЬ.bat. Программа установит зависимости, скачает русскую модель Vosk (с разрешением Apache 2.0) и запустится. В собранном EXE модель включена внутрь. Для тестов: python -m unittest discover -s tests -v.

Сборка Windows осуществляется посредством GitHub Actions и PyInstaller. EXE не подписан цифровой подписью и может вызвать предупреждение SmartScreen.
