# Стоп кадр — голосовое управление видеоплеером

Разработчик: Рамазанов Роман Валерьевич

Windows 10/11 x64. Офлайн распознавание русской речи.
Говорите «Стоп» для паузы, «Плей» для продолжения.

Выберите один из режимов управления:
- Пробел — большинство плееров и сайтов (окно видео должно быть активным)
- K — YouTube (если не выделено текстовое поле)
- Мультимедиа Play/Pause — приложения, поддерживающие Windows multimedia keys

Одна и та же клавиша Play/Pause у многих плееров переключает состояние. Чтобы двойная команда «Стоп» не возобновляла видео, повтор той же команды пропускается. Если состояние видео вручную изменили, внутренний учёт может рассинхронизироваться: перезапустите прослушивание. Не существует универсальной клавиши, гарантированно работающей с любым видеоплеером.

Установка: откройте GitHub Actions ветки stop-kadr-windows, выберите успешную сборку Build Stop Kadr Windows EXE, скачайте Stop-Kadr-Windows-EXE и извлеките Стоп кадр.exe.
Модель Vosk встраивается в EXE и не требует интернета после установки.
Автоматические тесты проверяют команды, но реальное воспроизведение на вашем Windows-компьютере необходимо испытать.


## Версия 1.1: VK Видео и ускорение

Для ускорения распознавания используется Vosk PartialResult: после 0,1 с устойчивого частичного результата команда выполняется **до окончания паузы**. Это уменьшает задержку, хотя реальная скорость зависит от микрофона и ПК.

Для VK Видео появился отдельный режим **«ВК Видео — пробел»**, выбор конкретного окна браузера «Окно видео» и кнопка «Обновить». Сначала щёлкните мышкой по видео, чтобы оно принимало пробел. Если окно выбрано, программа пытается активировать его перед отправкой клавиши. Новая отправка клавиш использует Win32 SendInput с физическими сканкодами, а не устаревший keybd_event.

Некоторые страницы и защищённые видеоплееры не принимают программные клавиатурные события. Абсолютную совместимость с каждым сайтом гарантировать нельзя.

При заметном рассогласовании управления (например, если видео вручную остановили) выключите и снова включите прослушивание, чтобы сбросить подавление повторных команд.


## Версия 1.2: переключение вкладок и видеоплееров

Устранена ошибка, когда после открытия первой вкладки «Стоп» срабатывал только в ней. В предыдущей версии подавление повторных команд было привязано к HWND браузера. У разных вкладок Chrome/Edge и других браузеров HWND может быть **одинаковым**. Теперь при каждом произнесении слова программа заново узнаёт активное окно и заголовок активной вкладки, а история команд ведётся отдельно по заголовку и окну.

По умолчанию включён режим **«Авто — текущая вкладка и видеоплеер»**. Для вкладок с заголовком YouTube используется K; для VK Видео и других — пробел. Не нужно выбирать браузер в списке или перезапускать распознавание при смене вкладки. Вручную переключать режим тоже можно прямо во время работы.

Если сайт не меняет заголовок при переключении видео или воспроизведение запущено вручную, нажмите **«↻ Сбросить»** в программе (микрофон не останавливается). Программа не читает внутреннее состояние HTML5-плеера, поэтому абсолютная синхронизация паузы и воспроизведения без расширения браузера недоступна. Чтобы браузер принимал клавиши, сначала один раз щёлкните на самом видео.
