# Стоп кадр — голосовое управление видеоплеером

Разработчик: Рамазанов Роман Валерьевич

Windows 10/11 x64. Офлайн распознавание русской речи.
Говорите «Стоп» для паузы, «Плей» для продолжения.

Выберите один из режимов управления:
- Пробел — большинство плееров и сайтов (окно видео должно быть активным)
- K — YouTube (если не выделено текстовое поле)
- Мультимедиа Play/Pause — приложения, поддерживающие Windows multimedia keys

Одна и та же клавиша Play/Pause у многих плееров переключает состояние. Чтобы двойная команда «Стоп» не возобновляла видео, повтор той же команды пропускается. Если состояние видео вручную изменили, внутренний учёт может рассинхронизироваться: перезапустите прослушивание. Не существует универсальной клавиши, гарантированно работающей с любым видеоплеером.

Установка: откройте GitHub Actions ветки stop-kadr-windows, выберите успешную сборку Build Stop Kadr Windows EXE, скачайте Stop-Kadr-Windows-EXE и извлеките Стоп кадр.exe.
Модель Vosk встраивается в EXE и не требует интернета после установки.
Автоматические тесты проверяют команды, но реальное воспроизведение на вашем Windows-компьютере необходимо испытать.
